# git-practice

## 简介

本仓库是软件开发综合实践课程的练习项目。

## 目录结构说明

```
git-practice/
├── index.html              # HTML 基础练习页面，演示标题、段落、列表、链接等常用标签
├── homepage/               # 个人主页目录
│   ├── index.html          # 个人主页页面，包含个人信息、爱好、常用链接及照片
│   └── images/
│       └── me.jpg          # 个人照片
├── theme-page/             # 主题介绍页目录
│   ├── index.html          # 乐队介绍页，介绍日本乐队 ヨルシカ（夜鹿）
│   └── images/
│       ├── yorushika.jpg                      # 乐队图片
│       ├── だから僕は音楽を辞めた.png          # 专辑封面：《だから僕は音楽を辞めた》
│       ├── エルマ.png                          # 专辑封面：《エルマ》
│       ├── 夏草が邪魔をする.jpg                # 专辑封面：《夏草が邪魔をする》
│       ├── 盗作.jpg                            # 专辑封面：《盗作》
│       └── 負け犬にアンコールはいらない.jpg    # 专辑封面：《負け犬にアンコールはいらない》

```
